# Ars Decor

GD's lackluster Ars Nouveau addon that adds decorative things. I promise nothing and this mod may go nowhere. This is my first foray into modding, after all...

## WARNING!

This is my first mod. This is my first addon. This is going to have problems. Here be (ender) dragons. Something as simple as a decoration addon logically shouldn't cause many crashing issues, if any at all, but I cannot guarantee stability!

This mod is also currently in what I'd consider "alpha" - definitely not complete! Only a handful of blocks are currently added - and most haven't been properly implemented!

## Dependencies
- [Fusion](https://github.com/SuperMartijn642/Fusion) 1.2.4 or newer (for this mod's connecting textures)
- [NeoForge](https://github.com/neoforged/NeoForge) 21.1.66 or newer
- [Ars Nouveau](https://github.com/baileyholl/Ars-Nouveau) 5.3.6 or newer *and all of its dependencies*
